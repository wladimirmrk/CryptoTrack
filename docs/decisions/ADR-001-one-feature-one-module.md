# ADR-001: Одна feature — один Gradle-модуль, слои — пакетами

- **Статус:** Accepted · **Дата:** 2026-09-06

## Контекст
Требование владельца проекта: многомодульность по принципу «одна feature = один Gradle-модуль», при этом
разделение presentation/domain/data — на уровне пакетов внутри модуля, без отдельных Gradle-модулей слоёв.

## Решение
Каждая фича из design-analysis — отдельный модуль `:feature:<name>` с пакетами
`presentation/`, `domain/`, `data/`. Зависимости направлены: presentation → domain ← data.

## Альтернативы
- Модули на каждый слой — отвергнуто владельцем: церемония сборки растёт непропорционально пользе при 7 фичах.
- Один модуль на все фичи — отвергнуто: теряются границы компиляции, время сборки и параллелизм.

## Последствия
- Быстрая инкрементальная сборка, чёткие границы фич.
- Просмотр слоёв требует дисциплины пакетов — правила проверяются Konsist-тестами (Phase 10).
