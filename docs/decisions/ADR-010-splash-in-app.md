# ADR-010: Splash в :app, без отдельного feature-модуля

- **Статус:** Accepted · **Дата:** 2026-09-06

## Контекст
Правило «одна feature = один модуль». Splash-экран — это навигационная заглушка: бренд + авто-переход,
без состояния, данных и ViewModel-логики.

## Решение
Splash реализуется в `:app` как стартовая destination NavHost (бренд из designsystem, авто-переход на
Market с сохранением splash-состояния).

## Альтернативы
- `:feature:splash` — модуль без домена/данных противоречит духу правила и не оправдан.

## Последствия
- На один модуль меньше; при появлении логики (онбординг, проверка ключа API) — пересмотреть и вынести.
