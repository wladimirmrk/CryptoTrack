# ADR-012: Dark-тема генерируется из seed-палитры

- **Статус:** Accepted · **Дата:** 2026-09-06

## Контекст
Settings содержит toggle Dark Mode, но дизайн-система определена только для Light Mode (токены design.md —
светлая схема).

## Решение
Light-схема — точные токены design.md. Dark-схема — сгенерированная M3-схема из того же seed-цвета
(`#0052ff`) со стандартными тёмными surface/on-цветами; success-токен — осветлённый вариант `#15803D`.

## Альтернативы
- Toggle хранится, но не влияет — обман пользователя.
- Ручная тёмная палитра — большие трудозатраты без макетов, риск несогласованности.

## Последствия
- Тёмная тема функциональна, но не сверяется попиксельно с макетами (их нет); ревизия в Phase 11.
