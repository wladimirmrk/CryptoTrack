# ADR-007: Графики — Vico + собственный Canvas-sparkline

- **Статус:** Accepted · **Дата:** 2026-09-06

## Контекст
Дизайн предполагает: area/line chart на Coin Details (таймфреймы 1H…ALL) и спарклайны (spec в design.md:
без осей, толщина 1.5, цвет по знаку изменения). В HTML-макетах график не нарисован.

## Решение
- Coin Details chart — библиотека Vico 2 (Compose-native, Material 3 совместимость).
- Sparkline в списках — собственный Canvas-компонент (`:core:designsystem`): тривиальный path, полный контроль
  цвета/толщины по spec дизайна.

## Альтернативы
- MPAndroidChart — View-модель рендеринга, несовместим с Compose-подходом.
- Всё на Canvas — на детали-графике нужны оси/подписи/жесты, писать самому дорого.

## Последствия
- Дополнительная зависимость (catalog + R8 keep-правила при необходимости).
