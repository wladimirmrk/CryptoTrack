# ADR-004: Navigation Compose с type-safe маршрутами; графы экспортируют фичи

- **Статус:** Accepted · **Дата:** 2026-09-06

## Контекст
Требование: Navigation Component/Compose. Риск: связанность фич через навигацию.

## Решение
1. Navigation Compose 2.9+ с `@Serializable` route-классами (kotlinx.serialization) — аргументы типобезопасны.
2. Маршруты и контракты — в `:core:navigation`. Каждый feature экспортирует `NavGraphBuilder.<feature>Graph(...)`
   с колбэками переходов (`onCoinClick: (String) -> Unit`); итоговый граф собирает `:app`.
3. Между экранами передаются только примитивы/id; данные подгружает целевой экран из репозиториев.

## Альтернативы
- Общий навигационный «роутер»-сервис в core — скрытая связность, сложнее тестировать.
- Строковые маршруты — ошибки аргументов в рантайме.

## Последствия
- Фичи не знают друг о друге; перестановка экранов — правка только в `:app`.
- Deep links не предусмотрены (в дизайне отсутствуют); добавить позже — route-классы это позволяют.
