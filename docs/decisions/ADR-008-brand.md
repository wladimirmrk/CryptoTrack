# ADR-008: Бренд приложения — CryptoTrack

- **Статус:** Accepted · **Дата:** 2026-09-06

## Контекст
В дизайне конфликт брендов: Splash-экран — «Apex Finance» (имя дизайн-системы), остальные 17 экранов —
«CryptoTrust». Владелец проекта выбрал третье имя: **CryptoTrack** (совпадает с каталогом проекта).

## Решение
Единый бренд — CryptoTrack во всём UI (splash, top bars, about, package `com.cryptotrack`).
Дизайн-система продолжает внутренне называться «Apex Finance» (как авторский источник токенов).

## Альтернативы
- CryptoTrust (17/18 макетов) — потребовало бы править только Splash, но имя отклонено владельцем.
- Apex Finance — потребовало бы править 17 макетов.

## Последствия
- При финальной визуальной сверке (Phase 11) расхождение текста бренда с макетами — ожидаемое и задокументированное.
