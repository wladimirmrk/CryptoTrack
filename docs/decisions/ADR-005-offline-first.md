# ADR-005: Offline-first, Room как single source of truth

- **Статус:** Accepted · **Дата:** 2026-09-06

## Контекст
Макет «Offline State» требует: нет сети → кэшированные данные + баннер «Showing cached data» + «Last updated».
Портфель и избранное должны работать полностью офлайн (локальные данные пользователя).

## Решение
UI читает только Room/DataStore (Flow). Сеть (CoinGecko) обновляет кэш: при открытии (если TTL истёк),
по pull-to-refresh и по foreground-тикеру Refresh Interval. Ошибка сети при валидном кэше — не ошибка для UI
(кэш + offline-баннер). `last_updated` хранится в cache_meta. 429 → backoff, UI продолжает показывать кэш.

## Альтернативы
- «Network-first с fallback на кэш» — сложные ветвления в каждом VM, мигания UI.
- Сторонний кэш OkHttp как источник — не контролирует TTL/схему, не работает для портфеля.

## Последствия
- Единообразные состояния во всех списках (loading только при пустом кэше).
- Миграции Room обязательны при изменении схемы — версии БД фиксируем в Phase 2.
