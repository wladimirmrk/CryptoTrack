# ADR-013: Портфель — только локальное хранилище

- **Статус:** Accepted · **Дата:** 2026-09-06

## Контекст
Дизайн предполагает ручной ввод активов (Add/Edit с полем «Amount Owned»); признаков бэкенда/биржевых
интеграций в макетах нет.

## Решение
Holdings хранятся только в Room на устройстве. Синхронизация, импорт с бирж, резервное копирование —
вне скоупа первой версии.

## Альтернативы
- Облачная синхронизация — требует бэкенда/аккаунтов, отсутствует в дизайне.

## Последствия
- Удаление приложения = потеря портфеля; при добавлении экспорта/бэкапа — отдельный ADR.
- Добавление того же коина повторно: merge холдингов (суммирование) — поведение фиксируем в Phase 8.
