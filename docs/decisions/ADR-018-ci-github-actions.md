# ADR-018: CI — GitHub Actions (build.yml)

- **Статус:** Accepted · **Дата:** 2026-09-11 · **Затрагивает:** Phase 12 (release), DoD «CI зелёный на main»

## Контекст
DoD Phase 12 требует зелёного CI на `main` (полный гейт: сборка + тесты + статический анализ). Репозиторий
разрабатывается локально на Windows; CI нужен как независимая проверка на нейтральной среде. Задача не требует
публикации артефактов (store-загрузка, secrets) — только гейт качества на push/PR в `main`.

## Решение
- **GitHub Actions**, файл `.github/workflows/build.yml`: триггеры `push`/`pull_request` в `main`.
- Раннер **ubuntu-latest**; **JDK 17 (temurin)** через `actions/setup-java`; кэш зависимостей и wrapper через
  `gradle/actions/setup-gradle` (кэширование включено по умолчанию).
- Один шаг сборки: `./gradlew assembleDebug testDebugUnitTest detekt lint` — тот же полный гейт, что и локально
  (AGENTS.md); Android SDK (включая platform 37) доустанавливается AGP автоматически — лицензии на
  GitHub-раннерах приняты заранее.
- **Без матрицы** (одна конфигурация): проект платформонезависим (нет shell-скриптов и путей Windows в сборке;
  `gradlew` хранится в git с LF), локальная среда — единственная эталонная конфигурация (JDK 17, Gradle 9.7).
  Матрица JDK/OS не даёт ценности: minSdk-инструменты фиксированы AGP, тесты не зависят от ОС.
- Публикации нет; секреты (keystore, CoinGecko API-ключ) в CI не используются: release-подпись опциональна и
  живёт в `local.properties` вне репозитория, API-ключ читается из local.properties/ENV и для CI пуст.

## Альтернативы
- GitLab CI / Jenkins — отвергнуто: репозиторий на GitHub, отдельная инфраструктура не оправдана.
- Матрица JDK 17/21 или windows-latest — отвергнуто: удвоение времени прогона без проверки реальных сценариев;
  Windows-раннер не отражает целевую среду (Android-устройство), а сборка детерминирована AGP.
- Отдельный job для detekt/lint — отвергнуто: гейт и так быстрый; разбиение усложняет чтение статуса PR.

## Последствия
- «CI зелёный» проверяется фактически после первого push в GitHub (выполняется вне локальной среды);
  локальный полный гейт идентичен шагам CI, расхождений не ожидается.
- Кэш Gradle ускоряет повторные прогоны; первая сборка на раннере скачивает platform 37.
- При добавлении publish-шагов (Play Store, артефакты) — новый ADR: потребуются secrets и другой гейт.
