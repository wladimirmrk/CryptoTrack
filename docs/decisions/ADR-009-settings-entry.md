# ADR-009: Вход в Settings — только с экрана поиска (по дизайну)

- **Статус:** Accepted · **Дата:** 2026-09-06

## Контекст
Единственная видимая в дизайне точка входа в Settings — иконка `settings` в хедере Search Results.
Предлагался дополнительный вход (gear в top bar Portfolio/Market) как UX-улучшение; владелец выбрал
«строго по дизайну».

## Решение
Settings открывается только иконкой в хедере экрана поиска, как в макете.

## Альтернативы
- Gear в top bar'ах основных экранов — отклонено владельцем (осознанный UX-риск).

## Последствия
- Обнаруживаемость настроек снижена; если владелец передумает — добавить иконку на Portfolio/Market top bar
  в рамках отдельного решения (пересмотр этого ADR).
