# ADR-003: DI — Hilt

- **Статус:** Accepted · **Дата:** 2026-09-06

## Контекст
Нужен DI-фреймворк для многомодульного приложения на Compose. Выбор владельца проекта.

## Решение
Dagger Hilt (KSP). ViewModel/Navigation/Compose интеграции из коробки, compile-time проверка графа,
стандарт для Android-модулей: каждый модуль объявляет свои `@Module` локально, `:app` — `@HiltAndroidApp`.

## Альтернативы
- Koin — быстрее сборка, DSL на чистом Kotlin, но ошибки графа только в рантайме; для автономной разработки
  агента compile-time проверки важнее.
- Ручной DI — нет масштабируемости при 17 модулях.

## Последствия
- KSP-плагин обязателен в convention-плагинах; время сборки выше Koin — принято.
